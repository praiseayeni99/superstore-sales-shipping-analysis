# Superstore Sales & Shipping Analysis – Project Documentation

This folder contains the project documentation for my Superstore Sales and Shipping Performance Analysis.

The documentation covers the project objectives, data preparation process, sales performance analysis, shipping performance analysis, business insights, and recommendations.

## Project Documentation

| Document | Description |
|---|---|
| Project Overview | Project background, objectives, dataset, and tools used. |
| Data Preparation | Excel and MySQL data preparation steps. |
| Sales Performance | Sales analysis, key findings, and business insights. |
| Shipping Performance | Shipping duration and shipping mode analysis. |
| Business Recommendations | Recommendations based on the analysis findings. |

## Tools Used

- Microsoft Excel – Dataset organization and preparation.
- MySQL – Date conversion, shipping days calculation, and customer order count.
- Power BI – Data analysis, DAX calculations, interactive dashboards, and visualizations.

## Project Objective

To analyze Superstore sales and shipping performance, identify business trends, and provide data-driven recommendations to support business decision-making.
