# Project Overview – Superstore Sales & Shipping Analysis

## 1. Project Background

This project focuses on analyzing Superstore sales and shipping performance using data analysis tools to identify sales trends, evaluate shipping efficiency, and generate business insights.

## 2. Project Objectives

The main objectives were to:

- Evaluate overall sales performance.
- Analyze monthly sales trends.
- Compare sales across customer segments, product categories, and geographical locations.
- Examine shipping duration across different shipping modes.
- Identify key business findings and provide actionable recommendations.

## 3. Dataset Overview

The project uses a Superstore sales dataset containing information about:

- Orders and order dates.
- Sales and customer details.
- Shipping dates and shipping modes.
- Customer segments and geographical locations.
- Product categories, sub-categories, and product names.

## 4. Tools Used

| Tool | Purpose |
|---|---|
| Microsoft Excel | Dataset organization and column rearrangement. |
| MySQL | Date conversion, shipping days calculation, and customer order count. |
| Power BI | Data analysis, DAX calculations, dashboard development, and visualizations. |

## 5. Project Workflow

1. Organized the dataset using Microsoft Excel.
2. Used MySQL to convert order and shipping dates into DATE data types.
3. Calculated shipping duration using DATEDIFF().
4. Calculated customer order count using COUNT(DISTINCT), a CTE, and LEFT JOIN.
5. Imported the prepared dataset into Power BI.
6. Developed sales and shipping performance dashboards.
7. Created DAX measures, analyzed trends, and presented business insights and recommendations.

## 6. Project Deliverables

- SQL data preparation script.
- Interactive Power BI dashboard.
- Sales performance analysis.
- Shipping performance analysis.
- Business insights and recommendations.
